# Publishing brand logos

Monochrome SVG brand marks from [Simple Icons](https://github.com/simple-icons/simple-icons), retrieved 2026-10-22 from `icons/{youtube,tiktok,instagram,meta,whatsapp,x}.svg`. Simple Icons is CC0-1.0; brand marks remain trademarks of their respective owners.

These source SVGs are bundled inline into `publishing-platforms.js` with decorative accessibility attributes. Visible platform labels provide accessible names. No external logo request is made by the Studio.
