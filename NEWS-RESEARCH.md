# News research

Select News and a topic in Describe Your Story. In the storyboard, open the floating AI menu and select Research the Web. Edit the prompt, item count and date range, then research. Review source links and publication dates, select items and create the storyboard. Each selected item produces one shot. Replacing an existing draft requires confirmation.

The frontend and server update must both be deployed. Publishing GitHub Pages updates the frontend only. Existing AI and storage connections are required; a GPU is not required. The UI reports when the server update is unavailable. No schedule or automatic publishing is enabled.

Validation covers source provenance, selected-item integrity, shot count, topic visibility, cancelling replacement and preserving concurrent edits.
