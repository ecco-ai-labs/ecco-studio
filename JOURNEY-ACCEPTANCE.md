# Guided journey acceptance — 2026-10-20

Entry: Tell Your Story → New Story → category → workflow. Go to Studio opens the existing tools. Existing Story lists connected storage records and browser drafts, grouped by saved workflow; old unclassified stories remain under Other Stories.

## Shared acceptance checks

1. Open the selected starting form, enter title/source and directions; save. Storage must be connected to create a persistent story.
2. Build/review script sections or storyboard shots. Back/Next preserves drafts. Creative directions must never be added as spoken words.
3. Continue to Audio: a new draft takes exact scene narration. Editing it and returning must preserve the edits. Use Storyboard Script is explicit replacement, with confirmation.
4. For video, prepare scene images, then open Generate Video. Storyboard images, shot text and an unambiguous story recording carry forward; saved video edits must not be overwritten.
5. Run one short generation on a connected supported worker. While running, use existing clip/progress controls. Failed generation must not imply completion.
6. Review only this story's finished output. Download, approve or move to Trash. Audio has script export; video can open the existing publishing screen.
7. Reopen from Existing Story and confirm the saved stage, settings, script and selections. Browser-local setup is not cross-device sync.
8. For recurring work, Next Chapter/Lesson/Episode starts another entry with workflow/voice defaults, leaving the prior production intact.

| Journey | Specific check |
|---|---|
| Audiobook | Chapter text → script sections → narrator → audio review; no visual stages |
| Podcast | Episode brief → script → host/voice controls; Audio or Video output |
| Audio Drama | Scene/dialogue → speaker turns in Audio → audio review |
| News Channel | Coverage/sources → existing news research/storyboard → narration/presenter → video |
| Documentary | Subject/questions/sources → storyboard → narration/images/video |
| Original Animation | Story/characters/style → storyboard → voice/image/video controls |
| Marketing Video | Product/audience/call to action survive in AI context |
| Social Video | Platform/hook survive in AI context |
| Book Adaptation | Chapter/cast/style survive; Next Chapter retains production defaults |
| Teaching Series | Audience/learning objectives survive; Next Lesson retains defaults |
| Training Series | Procedure/demonstration directions survive |
| Presentation | Outline/audience/takeaway survive; images generated, not a slide-engine export |
| Music or Ambient Video | Select source media; no music composition model is added |
| Localization or Dubbing | Select sources and available transcript; generate adapted speech/new video; original-film exact redubbing is not implemented |
| Repurpose Content | Select sources/transcripts; use visual reference analysis for a new render; timeline editing of existing footage is not implemented |
| Custom Production | Audio/Video choice controls visible stages |

## Evidence and boundaries

Automated fixtures cover all 16 route definitions, forms/metadata, exact narration transfer, preserving edits, story-scoped result gates, menu dismissal, video reference/audio/script handoff, and saved-shot reopening. They stub services; they do not prove GPU, audio model, OAuth or renderer behavior.

No paid generation or public YouTube publishing is part of UI verification. Tests of those require authenticated storage, ready workers and a configured YouTube backend. The checked-in independent storage service reports YouTube unavailable; automatic publishing/scheduling are not delivered by this change. Audio service length limits still apply; whole-book batch synthesis/assembly is not implemented.
